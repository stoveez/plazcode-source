# UltraLab inside PlazCode (Ultra)

In PlazCode this pack is the **Ultra** thinking level. The pack itself comes from UltraLab v2, built on the
SyphoDev Roblox skills (see LICENSE-SyphoDev.txt) and the Check-UI standard (see ONLINE-SOURCES.md).

What PlazCode adds around it:
- The AI reads this folder through the `ultralab_read` tool (list, read in pages, search). Nothing here runs by itself.
- `roblox_docs` searches and reads create.roblox.com/docs so every Roblox API can be verified.
- Each request that names a Roblox area gets the full text of the matching skills and agents, up to a size limit.
- This folder is read-only inside PlazCode. Notes learned in a task are offered to the user as files in their own project.
- Anything that uploads, installs, calls a paid service or spends credits needs the user's clear yes.

Keep LICENSE-SyphoDev.txt, the font licence (skills/ul-ui-builder/references/fonts/OFL.txt) and ONLINE-SOURCES.md
with any copy of this folder. Credit: SyphoDev (https://www.youtube.com/@SyphoDev).
