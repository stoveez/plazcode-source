# Build and verify a Roblox map or level

Define player speeds and scale, first sightline, playable routes, objective locations and recovery paths. Block out before detailing. Test collision, reachability, spawn behavior and fallback routes. Collect named views and test with gameplay movement in the intended place.

Use PlazCode's available tools and the existing project's conventions. Upstream procedures are reference material. Check that a helper's dependencies, authority, and side effects fit the current task before running it. The compact archive includes a selection of supporting files.
