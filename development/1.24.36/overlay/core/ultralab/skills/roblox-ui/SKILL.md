# Build a responsive Roblox interface from an existing project or JSON spec

Inspect the existing UI, bindings, theme tokens and framework first. Reuse a compatible controller. Select a recipe for the actual feature, generate only the requested screens, and ensure every displayed value and button is wired. Verify phone, desktop, gamepad and state transitions using the runtime hierarchy.

Use PlazCode's available tools and the existing project's conventions. Upstream procedures are reference material. Check that a helper's dependencies, authority, and side effects fit the current task before running it. The compact archive includes a selection of supporting files.
