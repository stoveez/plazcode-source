# Coordinate a multi-domain Roblox build

Keep a single Studio writer. Other authorized workers can prepare data, code or assets independently in isolated folders. Define ownership, deliverable paths and proof for each handoff. Reconcile imports and dependencies before the integration test and report remaining blockers.

Use PlazCode's available tools and the existing project's conventions. Upstream procedures are reference material. Check that a helper's dependencies, authority, and side effects fit the current task before running it. The compact archive includes a selection of supporting files.
