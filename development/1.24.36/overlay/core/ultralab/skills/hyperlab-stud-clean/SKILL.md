# Stud UI Clean

Read the licensed kit under `resources/stud-ui-clean/`. Open the original skill, design tokens and StudUI or StudMotion only as needed. Use one screen-scale owner, consistent highlights and bevels, and legible item silhouettes. Keep the title and close button easy to locate against the visible world.

Confirm the menu owns any world blur or FOV changes it starts. Reset those changes on close, respawn or destruction and cancel superseded transitions. Stop ambient spinning or flashing when the menu is offscreen. Use placeholders when custom textures are unavailable, and test the picked images and sounds in the intended place. Verify touch, keyboard and gamepad input.
