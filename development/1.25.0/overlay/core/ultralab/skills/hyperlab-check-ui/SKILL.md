# Check-UI Clean

The reference kit is available under `resources/check-ui-clean/` in the HyperLab folder. Open its original SKILL, design system and the chosen module or example with `ultralab_read`. In an existing installation, inspect the current CheckUI modules before changing their calls.

Use the reference's dense slate canvas, contrasting header, hard bevels, clear price and state hierarchy, and readable dark text strokes. Match the archetype only when it fits. A codes form, rebirth comparison, daily claim and shop each expose different states. Use a solid fallback if the checker texture is unverified, private or unreadable in the place.

Read component names and methods from the supplied source. Verify the texture, images and sounds in the actual place. Check touch sizing, controller selection and the active/inactive visual states independently of the look.
