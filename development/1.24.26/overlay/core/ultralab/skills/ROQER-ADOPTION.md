# What this pack took from Roqer, and what it did not

Source: S4US/Roqer (https://github.com/S4US/Roqer), licence GNU AGPL-3.0.

Roqer is an AGPL-3.0 project. Nothing was copied from it: no code, no skill text, no config
values beyond version numbers from a public guide. The ideas below were rebuilt from scratch.

Taken as ideas:
- A compile check on every Luau write (`luau-compile-gate`), in the spirit of Roqer's write-time syntax check.
- A toolchain skill that pins tool versions (`roblox-tooling`).
- Skills for topics Roqer covers and this pack did not: input, camera, physics, NPC AI, server data,
  audio, localization, monetization, analytics, and a publish checklist.

Not taken: Roqer's Studio plugin, its MCP server, its desktop app and its tests. Those are AGPL code.
