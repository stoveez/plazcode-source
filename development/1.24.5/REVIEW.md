Validation: all exact-source platform CI jobs passed. See release-validation-1.24.5.

It follows the latest actual user request’s language while preserving code/API names and exact startup protocol. DataStore safety prevents saving defaults after failed loads and requires bounded retries. UI and Luau checks preserve ownership, lifetime, documented signatures and truthful reporting. Full context is marked delivered only after a successful send, scoped to provider conversation and session generation. Mid-conversation activation includes the method once; later turns use short reminders. An unsent, stopped or failed send cannot mark the policy delivered. Global Roblox instructions remain 4,067 characters (previously 10,592); no live provider latency measurement is claimed.

No production exception or provider failure is treated as success.

The provider-preservation suite permits this specifically reviewed helper and still protects 1,080 original function bodies.

Existing localized, cold/hydrating composer, paste/upload, cancellation, foreign-draft and provider preservation suites remain required.
