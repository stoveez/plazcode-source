SelectionGroup is false by default. When true, it exposes SelectionBehaviorUp, Down, Left and Right, which control whether gamepad selection can leave the group. Each defaults to SelectionBehavior.Escape. Read on the docs page (fetched with http_get, keyword SelectionGroup).
