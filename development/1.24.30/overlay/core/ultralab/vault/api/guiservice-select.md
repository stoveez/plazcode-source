Signature: GuiService:Select(selectionParent: Instance): (). Called on the PlayerGui or a descendant, it searches the selectable, visible, on-screen GuiObjects under selectionParent and sets SelectedObject to the one with the smallest SelectionOrder. Fetched with http_get, keyword Select.

- See also [[guiobject-selectionorder]]
