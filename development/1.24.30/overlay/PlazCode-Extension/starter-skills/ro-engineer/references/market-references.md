# Market references (snapshot)

**Snapshot: 2026-10.** Popularity and mechanics change fast. Before relying
on this, re-check that each game is still performing and still works this
way. When it goes stale, update the table; the framework in `game-loops.md`
stays the same.

This snapshot comes from a creator's breakdown of the base-and-collect
simulator/tycoon niche. Use it to map a reference game's building blocks,
then pick your innovations. It is analysis, not a blueprint to copy.

## Building-block matrix

| Block | Ride a Pet | Steal an Egg | Escape Tsunami for Brainrots | Kick a Lucky Block | Dig and Clean | Surf and Rescue |
|---|---|---|---|---|---|---|
| Fantasy (verb) | Ride a pet | Steal a thing | Escape with a valuable | Kick to unlock | Dig up treasure | Save animals |
| Unique mechanic | Exploration | Timed egg restock | Pressure-valve level design | Skill check (timing bar) | Cleaning | Cleaning + surfing |
| Core loop | Leave base, get thing | same | same | same | same | same |
| RNG source | Spawn table | Spawn table (restock) | Spawn table | Roll on kick | Spawn table | Spawn table |
| Reveal timing | Post-acquisition roll | Post-acquisition roll | Pre-acquisition (visible, no roll) | Pre-acquisition roll | Post-acquisition roll | Post-acquisition roll |
| Level design | Radial | Linear | Linear (with safe pockets) | Linear | Simple / islands | Linear |
| Tension | Time pressure (egg cracks) | PvPvE (monster + players) | PvE (tsunami), pulsed | PvE (tsunami) | None / mild | PvE (shark, stingray) |
| Progression | Get faster | Get faster | Get faster | Get stronger | Get stronger (better shovel) | Get faster |
| Collection | Pets | Pets | Brainrots (pets) | Pets | Treasure | Animals (pets) |

## Per-game notes

**Escape Tsunami for Brainrots:** one of the originals in this wave. It made
linear level design popular (rarer items further from base) and made the
level itself the mechanic: safe troughs along the route turn each run into
repeated tension and release, plus a push-or-retreat decision. Rarity is
visible in the world, so route choice replaces a roll.

**Kick a Lucky Block:** very close to Escape Tsunami. It changes the verb to
kicking, moves the roll in front of the player (the block rolls when kicked),
and adds a skill check so luck has a skill element. Progression is strength,
not speed. It shows a live ops team can keep a near-clone going.

**Steal an Egg:** takes the timed shop restock popular in garden games and
moves it into the world: eggs respawn on a global timer. On top of the usual
PvE chase it adds PvP stealing. Restock-driven scarcity makes the PvP sharper.
Tension stays high from pickup until the safe zone.

**Ride a Pet:** the biggest set of changes in this list. It brings
creature-exploration games into the simulator loop with radial level design
and an open world. It creates tension with no monster at all: the egg hatches
on a timer, so the trip home is a race. New fantasy, mechanic, level design
and tension type all at once.

**Dig and Clean:** a new verb pair. Digging up an item, then cleaning it, is
a satisfying second step. Simple island level design, unlocked over time.
Weakest on tension (only the effort of digging), which leaves room for a
competitor.

**Surf and Rescue:** mechanically close to Dig and Clean (the same kind of
processing mechanic), but adds the block Dig and Clean was missing: clear PvE
tension (sharks chase you) on a linear route. Its "save animals" fantasy
likely reaches a different audience than the steal/escape games, which is
the main point: a fantasy change can win a new audience instead of fighting
over an existing one.

## Patterns across the snapshot

- The **core loop is identical** in all six. Nobody won by changing it.
- **Fantasy and unique mechanic** are where each game stands out.
- **Linear level design** is the default. Radial and island layouts are the
  exceptions and stand out because of it.
- **Tension is near-universal.** The one game without real tension is the
  obvious target for a competitor.
- **Progression** is almost always faster or stronger. **Collection** is
  almost always pets, with treasure as the exception.
- Mechanics are often **borrowed from another genre** (restock from garden
  games, exploration from creature games) rather than invented.

## Worked example: reference → twist

The source creator's own game used Steal an Egg as its reference:

| Block | Steal an Egg | Twist | Changed? |
|---|---|---|---|
| Fantasy | Steal a thing | Raise a thing | Yes: reaches a different audience |
| Unique mechanic | Egg restock | Egg restock + feeding | Yes: feeding added |
| Core loop | Leave base, get thing | same | No |
| RNG | Spawn table, post-acquisition | same | No |
| Level design | Linear | same | No |
| Tension | PvPvE | same | No |
| Progression / collection | Faster / pets | same | No |

Two changes in foundation blocks, everything else proven. That's the "about
20%" version: aimed at a solid mid-size game, not a chart-topper. Compare
Ride a Pet, which changed four blocks at once.
