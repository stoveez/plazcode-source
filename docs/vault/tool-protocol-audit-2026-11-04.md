Native unknown command now names the requested tool instead of its FNV number. E_ACCESS names required capability and user control; E_MATCH tells how to correct the file match.
2. **Capabilities:** SYSTEM_STATE includes machine-readable CAPABILITIES from actual native connection/local_full and Safety state. A stale Full PC menu choice never claims native permission. Unknown permission requests plazcode_status. Engine-specific disconnected/read-only cases tested.
3. **Formatting tolerance:** complete normal commands already accept prose and json/JSON/text/javascript/unlabelled fences; verified and prompt aligned. 4. **Paths:** sandbox accepts native absolute paths only INSIDE canon_root through canonical deepest-existing-ancestor/symlink/junction checks. Outside root, prefix siblings, traversal/dangling links and foreign-OS paths remain refused; Full access/allowlists unchanged. Builtin results echo resolved_paths without breaking existing JSON fields or text consumers.
5. **Preview:** write_file/edit_file preview:true returns exact contextual diff, before/after hashes/bytes, line endings, resolved path and changed flag; no write, mkdir, undo snapshot or task mutation. Exact local native names + boolean true only; arbitrary flags/add-ons retain mutation gates. Previews work in Read-only. Native Safety now gates even without undo ID (old shortcut bypass removed); E_READ_ONLY/E_CONFIRMATION_REQUIRED preserve explicit action/cause.

Images remain actual uploads. Error codes and original causes remain. Large results retain exact original text and expose a complete next_call {command,params}. Reader pages fit the serialized envelope AFTER JSON escaping, preserve newline/tab/CRLF/quotes/backslashes/emoji, never recursively repage and remain chat/engine scoped.
