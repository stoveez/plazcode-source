---
title: Envoyer un rapport de débogage
summary: Comment partager ce qui a échoué pour que ce soit corrigé vite.
date: 2026-10-21
---
1. Ouvrez **Paramètres > Debug**.
2. Cliquez sur le bouton de copie. Le rapport liste les erreurs récentes de PlazCode et du site de l’IA.
3. Collez-le dans le canal d’assistance du Discord avec une phrase sur ce que vous faisiez.

Le rapport est créé sur votre ordinateur. Lisez-le d’abord si vous voulez vérifier ce qu’il contient.
