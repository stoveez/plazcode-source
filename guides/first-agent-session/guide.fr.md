## Choisir un moteur
Dans l’Overview, la section Agent propose un sélecteur de moteur :
- **RobloxScript** modifie le jeu Roblox ouvert via Roblox Studio.
- **AgentScript** travaille sur des fichiers et des commandes dans un dossier de votre ordinateur.

## Décrire le travail
Écrivez votre demande dans le chat de l’IA comme d’habitude. Soyez précis sur ce que vous voulez créer ou modifier.

## Suivre le déroulement
La barre montre ce que fait l’IA, étape par étape. Vous pouvez l’arrêter à tout moment avec le bouton d’arrêt. Les réglages de sécurité, comme le mode lecture seule et la confirmation avant suppression, se trouvent dans **Paramètres > Sécurité**.
