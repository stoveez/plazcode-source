PlazCode 由兩個部分協同運作：**桌面應用程式**和**瀏覽器擴充功能**。請兩個都安裝。

## 安裝桌面應用程式
1. 從 [PlazCode 下載頁面](https://github.com/stoveez/PlazCode/releases)下載適合你電腦（Windows 或 Mac）的 PlazCode zip。
2. 解壓縮後開啟 PlazCode。
3. 視窗開啟後，PlazCode 會先檢查更新，然後顯示你的 Overview。

關閉視窗後，PlazCode 會在背景繼續執行。再次開啟即可讓視窗回來。

## 加入擴充功能
1. 開啟瀏覽器（Chrome、Edge 或 Brave）的擴充功能頁面。
2. 開啟 **Developer mode**。
3. 選擇 **Load unpacked**，然後選取 zip 裡的 **PlazCode-Extension** 資料夾。
4. 在 Firefox 中，使用同一個 zip 裡的 **PlazCode-Extension-Firefox** 資料夾，並從偵錯頁面載入。

> 請先移除擴充功能的任何舊副本，避免同時存在兩個版本。

## 確認運作正常
開啟一個支援的 AI 聊天頁面。頁面上會出現 PlazCode 列。應用程式的 Overview 中，**橋接**應顯示為已連線。
