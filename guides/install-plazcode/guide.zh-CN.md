PlazCode 由两部分协同工作：**桌面应用**和**浏览器扩展**。请两个都安装。

## 安装桌面应用
1. 在 [PlazCode 下载页面](https://github.com/stoveez/PlazCode/releases)下载适合你电脑（Windows 或 Mac）的 PlazCode zip。
2. 解压后打开 PlazCode。
3. 窗口打开后，PlazCode 会先检查更新，然后显示你的 Overview。

关闭窗口后，PlazCode 会在后台继续运行。再次打开即可恢复窗口。

## 添加扩展
1. 打开浏览器（Chrome、Edge 或 Brave）的扩展页面。
2. 打开 **Developer mode**。
3. 选择 **Load unpacked**，然后选中 zip 里的 **PlazCode-Extension** 文件夹。
4. 在 Firefox 中，使用同一个 zip 里的 **PlazCode-Extension-Firefox** 文件夹，并从调试页面加载。

> 请先删除扩展的任何旧副本，避免同时存在两个版本。

## 检查是否正常
打开一个受支持的 AI 聊天页面。页面上会出现 PlazCode 栏。应用的 Overview 里，**桥接**应显示为已连接。
