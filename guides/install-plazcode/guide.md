PlazCode has two parts that work together: the **desktop app** and the **browser extension**. Install both.

## Install the desktop app
1. Download the PlazCode zip for your computer (Windows or Mac) from the [PlazCode downloads page](https://github.com/stoveez/PlazCode/releases).
2. Unzip it and open PlazCode.
3. When the window opens, PlazCode checks for updates, then shows your Overview.

Closing the window hides PlazCode in the background. Opening it again brings it back.

## Add the extension
1. Open your browser's extensions page (Chrome, Edge or Brave).
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and pick the **PlazCode-Extension** folder from the zip.
4. On Firefox, use the **PlazCode-Extension-Firefox** folder from the same zip and load it from the debugging page.

> Remove any older copy of the extension first, so you never run two versions at once.

## Check that it worked
Open a supported AI chat. The PlazCode bar appears on the page. The Overview in the app should show the **Bridge** as connected.
