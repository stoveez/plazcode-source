PlazCode состоит из двух частей, которые работают вместе: **приложения для компьютера** и **расширения для браузера**. Установите обе.

## Установите приложение для компьютера
1. Скачайте zip-архив PlazCode для вашего компьютера (Windows или Mac) со [страницы загрузок PlazCode](https://github.com/stoveez/PlazCode/releases).
2. Распакуйте его и откройте PlazCode.
3. Когда окно откроется, PlazCode проверит обновления и покажет вашу Overview.

Если закрыть окно, PlazCode продолжит работать в фоне. Откройте его снова, чтобы вернуть окно.

## Добавьте расширение
1. Откройте страницу расширений браузера (Chrome, Edge или Brave).
2. Включите **Developer mode**.
3. Выберите **Load unpacked** и укажите папку **PlazCode-Extension** из архива.
4. В Firefox используйте папку **PlazCode-Extension-Firefox** из того же архива и загрузите её через страницу отладки.

> Сначала удалите любую старую копию расширения, чтобы не было сразу двух версий.

## Проверьте, что всё работает
Откройте поддерживаемый чат с ИИ. На странице появится панель PlazCode. В Overview приложения **Мост** должен отображаться как подключённый.
