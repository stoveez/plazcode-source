**Vault 메모리**는 AI가 작업하면서 읽고 업데이트하는 연결된 노트 폴더로, 채팅이 바뀌어도 프로젝트를 잊지 않게 해 줍니다.

## 노트 보기
**설정 > Memory**를 열고 vault 버튼을 클릭하세요. 노트와 노트 사이의 연결을 보여 주는 창이 열립니다.

## 끄기
AI는 노트를 자동으로 작성합니다. 같은 Memory 설정에서 끌 수 있습니다.

## 작업 검토
이미지 기반 작업에서는 AI가 별도의 비평 채팅에 결과 점수를 매기게 하고, 통과할 때까지 다시 만들 수 있습니다.
