The **Bridge** is the link between the browser extension and the desktop app.

## Try this
1. Make sure the PlazCode app is open. Closing the window only hides it, so check the background.
2. Reload the extension in your browser, then refresh the AI chat tab.
3. Make sure the app and the extension are the same version. Update the older one.

If it still says waiting, open **Settings > Debug**, copy the report, and send it in the Discord.
