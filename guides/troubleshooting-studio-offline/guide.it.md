## Controlla in quest’ordine
1. Roblox Studio è aperto con il tuo gioco caricato.
2. In Studio attiva il server MCP: **Assistant > Manage MCP Servers > Enable Studio as MCP server**.
3. Riavvia Studio e guarda la scheda **Roblox Studio** nell’Overview.

Se l’app dice che manca l’avvio MCP di Studio, potresti dover prima installare o aggiornare Roblox Studio.
