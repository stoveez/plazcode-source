## क्रम से जाँचें
1. Roblox Studio खुला है और आपका गेम लोड है।
2. Studio में MCP सर्वर चालू करें: **Assistant > Manage MCP Servers > Enable Studio as MCP server**।
3. Studio को रीस्टार्ट करें और Overview में **Roblox Studio** कार्ड देखें।

अगर ऐप कहे कि Studio MCP लॉन्चर नहीं मिल रहा, तो पहले Roblox Studio इंस्टॉल या अपडेट करना पड़ सकता है।
