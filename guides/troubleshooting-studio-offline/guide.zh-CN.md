## 请按顺序检查
1. Roblox Studio 已打开，并且你的游戏已加载。
2. 在 Studio 中开启 MCP 服务器：**Assistant > Manage MCP Servers > Enable Studio as MCP server**。
3. 重启 Studio，并查看 Overview 中的 **Roblox Studio** 卡片。

如果应用提示找不到 Studio MCP 启动器，可能需要先安装或更新 Roblox Studio。
