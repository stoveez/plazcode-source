---
title: Roblox Studio apparaît comme Offline
summary: PlazCode ne parvient pas à se connecter à Roblox Studio.
date: 2026-10-21
---
## Vérifiez dans cet ordre
1. Roblox Studio est ouvert avec votre jeu chargé.
2. Dans Studio, activez le serveur MCP de Studio : **Assistant > Manage MCP Servers > Enable Studio as MCP server**.
3. Redémarrez Studio et regardez la carte **Roblox Studio** dans l’Overview.

Si l’application indique que le lanceur MCP de Studio est introuvable, il faudra peut-être d’abord installer ou mettre à jour Roblox Studio.
