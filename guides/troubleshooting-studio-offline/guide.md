## Check these in order
1. Roblox Studio is open with your game loaded.
2. In Studio, enable the Studio MCP server: **Assistant > Manage MCP Servers > Enable Studio as MCP server**.
3. Restart Studio, then look at the **Roblox Studio** card on the Overview.

If the app says the Studio MCP launcher is missing, Roblox Studio may need to be installed or updated first.
