## Sprawdź po kolei
1. Roblox Studio jest otwarte z wczytaną grą.
2. W Studio włącz serwer MCP: **Assistant > Manage MCP Servers > Enable Studio as MCP server**.
3. Uruchom Studio ponownie i spójrz na kartę **Roblox Studio** w Overview.

Jeśli aplikacja informuje, że brakuje programu uruchamiającego MCP Studio, może być potrzebna instalacja lub aktualizacja Roblox Studio.
