## 請依序檢查
1. Roblox Studio 已開啟，而且你的遊戲已載入。
2. 在 Studio 中開啟 MCP 伺服器：**Assistant > Manage MCP Servers > Enable Studio as MCP server**。
3. 重新啟動 Studio，並查看 Overview 中的 **Roblox Studio** 卡片。

如果應用程式提示找不到 Studio MCP 啟動器，可能需要先安裝或更新 Roblox Studio。
