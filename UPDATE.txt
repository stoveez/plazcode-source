- Provider adapters remain hash-protected; the intentional core/main.js performance update has its own updated baseline hash.
- Existing parser, ChatGPT, Claude, skills, animation, v1.11, v1.12, v1.15, and v1.18 regression tests run in GitHub Actions.
- Desktop regression checks validate the settings relay, browser-tool relay, performance guards, and version.
- Rust cargo check and cargo test run on Windows.
- Rust tests include settings persistence across process reopen and normalization of invalid saved choices.
- The Windows workflow builds PlazCode.exe, embeds the branded Windows icon, and packages PlazCode-1.18.66.zip.
- Live authenticated provider smoke tests are still required before merging the draft branch because GitHub Actions cannot drive the user's logged-in AI website sessions.

Install / test:
1. Close the old PlazCode process completely before replacing files.
2. Keep your old folder outside the installation as a rollback copy if desired.
3. Extract PlazCode-1.18.66.zip and replace the previous PlazCode folder.
4. Reload the unpacked extension in chrome://extensions.
5. Refresh every already-open supported AI chat tab. Reloading the extension alone leaves the old content scripts running.
6. Run PlazCode.exe.
7. Change several desktop settings, close the window, reopen PlazCode.exe, and verify the settings remain unchanged.
8. Open Tools and verify RS, AS, PC, and MCP source labels appear as those tool sources become available.
9. Test the currently working AI websites in a normal chat and a long existing chat. Notion remains the known exception for this release.

Background behavior:
- X / Hide: hides the desktop UI but leaves the PlazCode bridge running.
- Launch PlazCode.exe again: reopens the already-running desktop instance.
- Settings > Exit PlazCode: fully exits the process.

Security boundary:
- Local command and desktop endpoints still require the pairing key.
- Optional MCP servers remain disabled until explicitly enabled.
- Roblox Studio MCP cannot be removed from the catalog.
- The pairing key stays outside the release ZIP.
- No new Chrome permissions were added.

Distribution:
- Distribute the complete PlazCode-1.18.66.zip.
- Keep the extension and desktop app from the same build together.
